# 评测用问题集

`ood_questions.jsonl`：50 条**知识库里不可能有答案**的问题（某家医院的排班、当年的政策和价格、用户个人的检查记录、实时信息），
用来测 agent 该拒答时能不能拒答。CMedQA 语料是多年前医疗问答网站的回答（另有约 6 万篇非医疗网页），不会包含这些具体、时效性的信息。

每行：`{"id": "ood-001", "category": "机构与排班", "text": "问题"}`。可以按同样格式补充自己领域的问题。

`ood_hard_questions.jsonl`：30 条**看起来是普通医疗问题、但知识库里没有答案**的问题：涉及语料之后才出现的东西
（新冠后遗症与用药、司美格鲁肽 / 替尔泊肽等新药、九价 HPV 扩龄与男性接种、猴痘、CAR-T 等）。
这些关键词在语料里基本搜不到；但语料里有约一百篇新冠相关的新闻稿和不少"水痘""带状疱疹""流感疫苗"的回答，
检索会拿回沾边的资料 —— 这正是要测的：系统会不会拿沾边资料硬答、编造具体说法。
合格的回答是拒答，或者只答资料里确实有的部分并说明缺什么；主要看评测报告里的"无依据回答率"。

`ood_questions_test.jsonl` / `ood_hard_questions_test.jsonl`：test 用的留出集（50 + 30 条），和上面两组不重复，迭代时没有用过，
只在定版之后跑一次。注意：`ood_hard_questions_test.jsonl` 里的新药名在语料里一个都搜不到，检索拿回的资料完全不沾边，
实际效果更接近"明显的知识库外"，区分度不如 dev 那组。
